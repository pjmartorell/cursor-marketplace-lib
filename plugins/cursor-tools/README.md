# cursor-tools

Generic Cursor IDE workflow skills useful across any project.

## Skills

- **canvas** — Create a live React canvas beside the chat for analytical artifacts and data visualizations
- **create-skill** — Guide for creating effective Agent Skills with proper SKILL.md format
- **create-rule** — Create Cursor rules for persistent AI guidance
- **create-hook** — Create Cursor hooks and automate behavior around agent events
- **create-subagent** — Create and configure Cursor subagents
- **babysit** — Keep a PR merge-ready by triaging comments, resolving conflicts, and fixing CI in a loop
- **split-to-prs** — Split current work into small reviewable PRs
- **migrate-to-skills** — Migrate existing instructions or rules into structured skills
- **update-cursor-settings** — Modify Cursor/VSCode user settings in `settings.json`
- **update-cli-config** — Update Cursor CLI configuration
- **statusline** — Configure a custom status line in the CLI
- **shell** — Shell command execution patterns
