# app-owner

Skills for the Loyal Guru Angular owner portal (`loyal-guru-app-owner-v2`).

## Skills

- **add-i18n-keys** — Add or update translation keys in i18n JSON files
- **add-config-driven-form** — Add or extend config-driven forms using `QuestionBase` and `QuestionControlService`
- **add-doc-and-rule** — Add a new documentation topic and matching Cursor rule
