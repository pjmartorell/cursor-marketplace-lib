# loyal-guru-api

Skills for the Loyal Guru Rails API (`loyal-guru-api`).

## Skills

- **add-permission** — Create a new permission and open a standalone PR following the convention
- **apartment-switch-misuse** — Identify unnecessary `Apartment::Tenant.switch` calls causing cache pollution
- **authorization** — Manage Pundit policies, Role permissions, and access control
- **cloudwatch-streaming** — Query AWS CloudWatch logs for the Streaming API Gateway
- **configurations** — Tenant-scoped Management API configurations
- **customer-attribute-sqid-audit** — Audit BigQuery→PostgreSQL `scheduled_query_id` mismatches
- **endpoint-permissions-audit** — Audit API endpoint permissions and authorization security
- **explain-code** — Explain code with visual diagrams and analogies
- **fetch-frontend-urls** — Find all frontend URLs affected by a backend API change
- **pumps** — Work with the Pumps system that uploads PostgreSQL data to BigQuery
- **review-pull-request** — Review a GitHub PR against its linked Jira issue requirements
- **safe-migrations** — Write safe, zero-downtime Rails database migrations
- **segment-engine** — Work with the Segment Engine for customer segmentation
- **semaphores** — Work with the Semaphore concurrency control system for Sidekiq
- **sidekiq-monitoring** — Query and analyze Sidekiq job lifecycle events from BigQuery
- **streaming-pipeline-troubleshooting** — Troubleshoot the streaming data pipeline
