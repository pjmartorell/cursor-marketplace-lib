# platform-ops

Operational and observability skills for the Loyal Guru platform.

## Skills

- **staging-label-assignment** — Check available staging slots and assign deploy labels to PRs
- **streaming-credentials-triage** — Triage Cloud Function/Cloud Run errors for GCP credentials and LaunchDarkly flags
- **transcript-analysis** — Analyze Cursor agent transcripts to rank MCP tool calls and skill usage
- **skill-usage-trace** — Find and explain every conversation where a specific Cursor skill was triggered
